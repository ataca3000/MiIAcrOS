# Changelog

Todos los cambios notables del proyecto se documentan en este archivo.

El formato está basado en [Keep a Changelog](https://keepachangelog.com/es-ES/1.0.0/)
y este proyecto sigue [Semantic Versioning](https://semver.org/lang/es/).

## [1.0.0] - 2024-01-01

### Añadido
- Interfaz de asistente IA con diseño Glassmorphism
- Efecto KITT (pulso neón) inspirado en "El Auto Increíble"
- Integración con Gemini API para procesamiento de lenguaje natural
- Soporte para modelos locales (Llama 3, Mistral) vía Ollama
- Reconocimiento de voz en español (Web Speech API)
- Panel de historial de conversación
- Panel de configuración con descarga del script backend
- Servidor WebSocket Python para automatización de escritorio
- Funcionalidad de resumen de páginas web
- Funcionalidad de copiar texto a Word vía PyAutoGUI
- Ventana draggable y redimensionable
- Atajos de teclado (Alt+M, Alt+S, Alt+R)
- Reorganización del proyecto en estructura `src/frontend`, `src/backend`, `src/shared`
- Documentación completa (README, DEVELOPMENT, ARCHITECTURE, API, CONTRIBUTING)
- Configuración Python con `requirements.txt` y `setup.py`
- Scripts de instalación para Windows y Linux/macOS
